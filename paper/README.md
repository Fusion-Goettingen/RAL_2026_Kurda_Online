# Raw results
This directory contains the raw results produced by all methods.
If you have downloaded the KITTI, MulRan and/or Odyssey datasets, you can use the `run_compare.sh` script to reproduce our result tables.
The evaluation on MulRan and Odyssey can take some minutes.

## Dependencies
Install all python dependencies with
```
pip install numpy scipy tabulate pykitti opencv-python pyaml
```
